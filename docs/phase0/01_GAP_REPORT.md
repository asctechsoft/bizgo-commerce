## 4. Business / real-world gaps (cannot be closed by engineering)

All BRD §13 + Spec §14 items D01–D12 remain **open**, and Phase 0 found **eight more** (D13–D20). Full register with safe defaults: `docs/phase0/02_BLOCKED_DECISIONS.md` and `docs/decisions/DECISION_LOG.md`.

Highlights that change engineering behaviour today:

- **No seller identity (D01), prices (D04), shipping fee source (D05), stock (D02), VAT policy (D14)** ⇒ `canPlaceOrder` is `false` for every real SKU; checkout is only exercisable on `TEST`-flagged fixtures in dev/test.
- **No OTP/email/SMS provider (D15)** ⇒ verification endpoints fail closed in production config; dev console transport only when `NODE_ENV!=production` and `DEV_OTP_CONSOLE=true`.
- **No hosting/domain (D10)** ⇒ Docker Compose local + staging profile only.

## 6. Risks accepted / deferred

1. Single backoffice Next.js app mixes admin and factory bundles (G08) — mitigated, revisit before factory external access.
2. Legal citations in BRD §11 (Luật TMĐT 122/2025/QH15, NĐ 248/2026/NĐ-CP, Luật BVDLCN) are **not verified by engineering**; no compliance claim, no "registered" badge will be shipped (D09).

4. Large table inventory (~110 tables in Spec §05) — migrated **per phase**, never all at once; ERD marks phase per table.
